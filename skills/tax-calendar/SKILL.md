# Налоговый календарь клиентов

Скилл разворачивает дашборд налоговых сроков: веб-страница (чистые HTML+CSS+JS, без сборки)
показывает по каждому клиенту, что и когда сдавать/платить, подсвечивает просрочку,
хранит отметки «выполнено» в браузере.

## Когда использовать

- Нужен такой же дашборд для своей практики или для коллеги-бухгалтера.
- Данные поменялись (новые клиенты, новый год) — нужно обновить данные.

## Как собрать с нуля

1. Подготовьте Excel-таблицу листом «План помесячно»: строки — клиенты,
   колонки парами «задача | статус» на каждый месяц, в тексте задачи дата вида «28.04: Текст».
2. Выгрузите непустые ячейки в текстовый дамп вида `r=<строка> c=<колонка> :: <текст>`
   (или попросите Claude Code сделать дамп через Excel COM).
3. Соберите `data.js` в формате:

```js
window.TAX_DATA = {
  clients: [{ name: 'ИП Пример', regime: 'УСН 6%', note: 'сотрудники, зп 5 и 20 число' }],
  tasks: [{ client: 'ИП Пример', monthKey: '2027-04', year: '2027', month: '04',
            date: '2027-04-28', raw: '1. 28.04: УСН аванс (1 кв)', text: '28.04: УСН аванс (1 кв)', status: '' }]
};
```

4. Попросите Claude Code: «разверни проект tax-calendar из скилла, данные — мой data.js».
   Он создаст `index.html`, `styles.css`, `app.js` и подставит ваши данные.

## Как обновить данные

Замените `data/data.js`. Имена клиентов — только ваши; в шаблоне репозитория они вымышленные.
Выполненные задачи хранятся в localStorage браузера (ключ `taxcal-done`), поэтому после
входа со своего компьютера отметки не потеряются.

## Проверка

Откройте `index.html` (или `npx serve .`). Должно быть: плитки-счётчики сверху,
фильтры (клиент / режим / статус / поиск), переключатель «По датам | По месяцам»,
клик по чекбоксу задачи переводит её в «выполнено» и сохраняется после перезагрузки.
